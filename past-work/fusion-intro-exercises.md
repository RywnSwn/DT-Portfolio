# Fusion 360 Intro Exercises

Two small class assignments (phone stand and name tag) made to get used to Fusion 360. Both were set by the teacher. Photos of the phone stand are in `../assets/phone-stand/`. No photos of the name tag yet.

## What it taught me
- Moving the camera around the model
- Extrude, including extruding into an object to cut it away
- Fillets
- Finding text, which showed me how many other tools there are
- Sketch was the hardest. I come from Blender, so I kept trying to scale and extrude like a plane. Now it feels easy.

## Name tag
- First version: the classic extruded name
- Then I tried a Chinese style pattern for the tag. It went badly, so I followed a tutorial to finish it. My files got messed up along the way (many copies), so I have no screenshots of it.
- A classmate liked the pattern idea and had it made for them, so I dropped it
- I switched to a "poke through" name, where the letters are cut all the way through the tag. Still a creative option.
- Problem found after printing: cut-through letters like A leave a small floating triangle in the middle. It has nothing holding it, so it does not stay in.

## Lesson for the chess board
- Think about the 3D printer's weak points while designing, not after printing
- Check for parts that have no support or nothing attached (floating islands, overhangs)
- Apply this to the board hinge so it does not fail or stick when printed
