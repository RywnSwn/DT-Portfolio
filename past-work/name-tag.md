# Name Tag (intro exercise)

Teacher-set exercise to get used to Fusion 360. Done before the Book Chess Board. No photos in the repo yet.

## What it taught me (Fusion 360 basics)
- Moving the camera
- Extrude, and that you can extrude into an object to cut it away
- Fillets (favourite tool)
- Using the search to find tools, which showed how much more Fusion has
- Sketch was the hardest to learn. I came from Blender, so I kept trying to scale and extrude it like a plane. Now it is easy.

## Versions
1. **Extruded name:** the classic version, text extruded up from the tag. Printed fine.
2. **Chinese-style pattern:** tried to be more creative. Followed a tutorial, but the files got messed up and split into lots of files. No screenshots survived. Dropped it.
3. **Poke-through letters:** the letters are cut all the way through the tag. Final version.

## What went wrong
- In letters like **A**, the small triangle in the middle was not connected to anything, so it fell out after printing
- Should have spotted it before printing: any "island" part needs to connect to the rest (or be designed differently)

## Lesson I carried forward
- Think about what the 3D printer is bad at before printing, not after
- Applies to the Book Chess Board: the print-in-place hinge must be designed so the parts don't fuse together
