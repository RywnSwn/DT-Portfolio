# Decisions

Newest at the top. Each entry: what was decided, why, and where the details are.

## Website style: basic and a little amateur on purpose (2026-09-29)
- **What:** plain HTML, CSS and JS, no framework, no build step, no code comments. Visual style is deliberately simple and a little rough, not slick.
- **Why:** matches the personal, homemade feel of the project rather than looking like a generated template.
- **Knock-on effects:** semantic HTML and accessibility (skip link, landmarks, alt text, aria-current, labelled controls) are still done properly, that part is not optional just because the look is basic.
- **Details:** `website/` folder, `context/current-state.md`

## Site hosted on GitHub, not Google Sites (from earlier)
- **What:** the portfolio site will live in this same repo and be hosted with GitHub Pages, not on Google Sites like last year's example project.
- **Why:** wanted everything in one place, and it is something to show for college.
- **Details:** `context/current-state.md`

## Redesign: static cover case + sliding folding board (2026-09-25)
- **What:** the cover is a fixed book-shaped case. The board folds and slides into it.
- **Why:** the first version (covers that open into the board) was too advanced
- **Knock-on effects:** the hinge moves to the board, and piece storage needs a new home
- **Details:** `context/current-state.md`

## Mortised (inside) hinge (from the first design, recheck after redesign)
- **Why:** clean book-spine look, panels close flush, board can open flat to 180°
- **Details:** `project/predesign-notes.md`

## Fold line on a square boundary
- **What:** the fold goes between columns 4 and 5, never through a square. Each cover is 4 columns wide.
- **Details:** `project/predesign-notes.md`

## Final project: Book Chess Board
- **What:** picked the book chess board over the earlier brainstorm ideas (charging pallet, shirt folder, tissue holder, time capsule, shooter)
- **Details:** `project/design-brief.md`, `brainstorms/2026-08-25-dt-ideas-brainstorm.md`
